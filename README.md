# Домашнее задание «Web-scrapping»

Скрипт получает первую страницу свежих статей Хабра и выводит публикации,
в preview которых встречается хотя бы одно ключевое слово.

## Запуск

Нужен Python 3.10 или новее и доступ к интернету.
Откройте терминал в папке с `main.py`:

```bash
python -m pip install -r requirements.txt
python main.py
```

Если в Windows команда `python` недоступна, используйте `py` вместо неё.

## Настройка и принцип работы

В начале `main.py` задаются слова:

```python
KEYWORDS = ["дизайн", "фото", "web", "python"]
```

`requests` загружает HTML, `BeautifulSoup` находит карточки статей.
Поиск идёт по всему тексту каждой карточки: автору, заголовку, хабам,
меткам и анонсу. Регистр не учитывается. Проверяется вхождение подстроки:
например, «фото» также найдёт «фотография», а «web» — «web-разработка».
Одна статья выводится один раз, даже если совпало несколько слов.

Формат вывода:

```text
<дата> – <заголовок> – <ссылка>
```

Дата берётся из атрибута `datetime` элемента `time`.
Ссылка преобразуется в абсолютную через `urljoin`.
Результат зависит от текущего содержимого ленты; отсутствие совпадений допустимо.
При сетевой ошибке или отсутствии ожидаемой разметки выводится сообщение об ошибке.

Обрабатывается только первая страница публичной ленты
https://habr.com/ru/articles/ — авторизация не требуется.
Персональная лента `/ru/feed/` не используется.
Полные тексты статей не загружаются: выполнена основная часть задания.
Если Хабр изменит разметку, CSS-селекторы в скрипте потребуется обновить.

git branch -M main

git push -u origin main

Замените `<URL_ВАШЕГО_РЕПОЗИТОРИЯ>` адресом своего репозитория.

`git add .`, `git commit` и `git push`.
